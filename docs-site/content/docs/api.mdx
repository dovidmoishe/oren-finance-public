## Start with MCP

The documented integration surface is the [remote MCP server](/docs/mcp). Its [tool reference](/docs/mcp/tools) describes the available tool names, inputs and permissions.

See [Public tools](/docs/tools) for an overview of the tools available through MCP.

The MCP URL is `https://api.oren.finance/mcp`. It is a protocol endpoint for MCP clients, not a conventional REST endpoint to open in a browser.

## REST and SDK documentation

A general-purpose public REST API contract and developer SDK reference are not published here yet. Internal application endpoints should not be treated as stable public APIs.

As public interfaces are released, this section can host generated OpenAPI reference pages alongside authored guides. No API key provisioning flow is currently documented.
